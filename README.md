# 🍽️ Smart Canteen Pre-Order & Token System

## 📌 Project Overview
The **Smart Canteen Pre-Order & Token System** is a Java-based desktop application developed to simplify college canteen operations. It allows students to view food menus, place orders, calculate bills, generate tokens, and track order status. Canteen staff can manage orders and update their status through an admin dashboard.

## 🎯 Objectives
- Reduce long queues and waiting time in college canteens.
- Simplify food ordering and billing.
- Generate tokens for easy order identification.
- Allow students to track their order status.
- Help canteen staff manage orders efficiently.
- Demonstrate Object-Oriented Programming concepts in Java.

## ✨ Features
- **Student Ordering:** Browse the menu and select food items.
- **Shopping Cart:** Add selected items and review the order.
- **Bill Calculation:** Calculate the total amount.
- **Token System:** Identify orders using tokens.
- **Live Order Status:** Check the progress of orders.
- **Kitchen Dashboard:** View and manage student orders.
- **User-Friendly Interface:** Built using Java Swing.

## 🛠️ Technologies Used
- **Programming Language:** Core Java
- **GUI:** Java Swing and AWT
- **Collections:** ArrayList and List
- **Table Management:** JTable and DefaultTableModel
- **IDE:** Eclipse / IntelliJ IDEA
- **JDK:** Java Development Kit (JDK 8 or later)

## 🧠 OOP Concepts
This project demonstrates the following Object-Oriented Programming concepts:
- **Encapsulation:** Organizing and protecting data within classes.
- **Inheritance:** Reusing properties and methods through class inheritance.
- **Polymorphism:** Supporting different implementations of methods.
- **Interfaces:** Defining common behaviour for classes.
- **Exception Handling:** Handling errors and invalid operations.
- **Collections Framework:** Managing menu items, cart items, and orders.

## 🚀 How to Run the Project

1. Install the Java Development Kit (JDK 8 or later).
2. Install Eclipse IDE or IntelliJ IDEA.
3. Clone or download this repository.
4. Import the project into your IDE.
5. Ensure all required Java classes are included.
6. Run `SmartCanteenApp.java`.
7. Use the dashboard to explore the available modules.

### Run Using Terminal
If all Java source files are in the same directory, open a terminal in that directory and run:

```bash
javac *.java
java SmartCanteenApp
```

## 📂 Project Modules
1. **Order Food (Student)** – Select menu items and place orders.
2. **Live Order Status (Student)** – View order progress.
3. **Kitchen Dashboard (Admin)** – View orders and manage their status.

## 💾 Data Management
The application uses Java Collections to manage menu and order information in memory. Data is available during the running session but is not permanently stored after the application closes unless database or file storage is added.
